# Coffee Marketplace API

## Project Goal

The goal of this project is to design and develop an API for an online marketplace dedicated to coffee and related equipment.

The platform enables customers to browse products, place orders, and complete payments securely and efficiently.

Sellers can manage their products, inventory, discounts, and sales activities, while system administrators are responsible for monitoring the platform, managing users, and controlling various system components.

The primary objective is to build a secure, scalable, and maintainable marketplace that facilitates product management, order processing, payment handling, and interactions between customers and sellers.
