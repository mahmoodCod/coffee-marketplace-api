# Coffee Marketplace API (NestJS app)

This folder contains the NestJS application source.

For the full project README — modules, setup, scripts, and API overview — see the repository root:

**[../README.md](../README.md)**

```bash
npm install
cp example.env .env
npm run migration:run
npm run seed
npm run start:dev
```

- API: http://localhost:3000  
- Swagger: http://localhost:3000/api/docs
